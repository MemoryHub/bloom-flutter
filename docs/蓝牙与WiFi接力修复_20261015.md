# 重置任务的蓝牙与 Wi-Fi 接力（2026-10-15）

本轮修复的是新建重置任务在蓝牙中断后无法联网继续的问题。服务器仍是展示参数的唯一来源，正常选图、作息、提前刷屏和联网预取执行代码不变。以下 v2 能力需要新 App 7059 与固件 1520 配套；旧协议正在执行的任务不强行改写为新协议。

## 现在的顺序

1. 云端登记重置任务，保留主人关系。设备未联网/未收到授权时显示等待，不提前解绑；相框关机也不假报完成。
2. 附近手机通过 Security1 和主人认证获取云签名授权；不在附近则设备下次联网领取同一任务。v2 手机已取授权却未送达也可由 Wi-Fi 接手。
3. 相框持久记录任务，清私人缓存并实际刷新欢迎页。保存的网络暂时隔离，只供这个重置任务联网，不允许旧展示任务或新配网使用。
4. 手机或相框转发设备 HMAC 清理凭证，云返回绑定设备和任务的签名确认；相框持久记录后撤销本地主人密钥。
5. 手机或相框提交第二份设备凭证，服务器同事务清除归属、邀请和设备展示设置，保留账号及云照片，返回最终签名确认。
6. 相框先持久保存最终确认，再清除网络、清理重置标志，完成后重启。断电发生在清网中途也能凭持久确认继续，不再依赖网络。

手机、设备两条路径复用相同任务与服务端归属清理事务。设备 journal 写入互斥并禁止迟到写入退回旧阶段；签名绑定设备、任务、协议和凭证。重复完成已结束的任务不会删除后来绑定的新主人。

## 断线的实际行为

| 情况 | 行为 |
|---|---|
| 相框有互联网、手机不在附近 | 相框联网领取并执行；休眠/关机时等待下次联网 |
| 相框有互联网、执行中手机离开或断网 | 相框继续推进相同 v2 任务，失败约 30 秒后重试 |
| 相框无互联网、手机有互联网且蓝牙可达 | 手机只搬运签名和凭证，协助相框完成 |
| 两端都不能访问服务器 | 保留已持久的阶段，等待恢复，不显示已确认解绑 |
| 云端完成后最后一条蓝牙确认丢失 | 相框用保留的网络重试；仍无网时，持有人再次扫码、提交设备真实最终凭证后可补送最终签名（无需旧主人密钥） |
| 重置中途掉电 | 读取 journal 继续；欢迎页检查点已落盘后不重复刷屏 |

Wi-Fi 接力要求保存的网络确实可以访问服务器。它不能解决当前公司 DHCP 故障，也不会把 Wi-Fi 关联成功当作联网成功。旧版 v1 journal 按旧流程恢复，不把已经清除的网络凭空恢复出来。

## 其他功能边界

- 设置与 OTA：云先保存设置/建立任务，附近 BLE 只提醒相框检查服务器。提醒失败不撤销已经保存的云设置，仍可在下次正常联网应用。
- 配网与删除网络：仍需附近蓝牙直连；未实现通过云远程传 Wi-Fi 密码。没有 DHCP 成功的候选不会覆盖原保存网络。
- 已有图库首播：仍需相框联网拉取原计划和照片，不能靠 BLE 提醒在无网时下载照片。
- 常驻 BLE 使用保留蓝牙的轻睡，不能称为真正深睡仍可连接。电池待机电流与完整显示周期尚需实物验收。

## 本轮补测：不调用 WiFi.config 的原生 DHCP

独立原 Arduino 2.0.11、无 BLE、只使用当前公司网络、凭据仅存 RAM；保留默认自动重连、默认 MIN_MODEM 和功率，不调用额外 `WiFi.config`。45 秒真机结果：关联事件 1、IP 事件 0、DHCP API 返回 0 / 状态 STARTED、断开原因 0，始终未取得 IP。由此排除“必须经过新增 App/BLE 管理、额外 IP/DNS config 调用才触发”这一条件；不能证明 AP 未收到请求或 DHCP 服务未回复。测试后已恢复 1520，仅写应用；Hash 与实际 v19 启动版本核验通过，无诊断固件遗留。

## 网络恢复后的真机验收顺序

1. 用已安装的 iPhone 7059 扫现役欢迎码，连接公司网络，必须真实取得 IP 并进入绑定完成；不清手机登录或云图库。
2. 选择已有图库，“完成并开始播放”后观察服务器任务、照片下载、真实刷屏及回报；不能只看 BLE ACK 判成功。
3. 相框正常联网时远离蓝牙提交重置，观察设备联网领取、真实欢迎页、云端完成和本地清网。
4. 新建 v2 重置后分别在“手机取了授权但尚未送达”和“已刷欢迎页但尚未收最终确认”处断开 BLE，相框联网继续同一任务，不能多建任务或重复清理后来主人。
5. 相框自然无网时用有网手机 BLE 完成；手机也无网时应保持待恢复，恢复后继续，不能假报成功。
6. 云端完成但最终 BLE 确认丢失后，再次扫码恢复；更换登录账号也只能提交设备真实 proof 补原最终签名，不能取得旧主人密钥。
7. 物理拔电覆盖最终签名持久化前后；签名前保留隔离网络，签名后无网也能完成清网；欢迎页已落盘的阶段不重复刷。
8. 重绑后验正常三周期、四姿态、保存作息/BLE提醒失败后下一次联网同步和 OTA；续航需独立供电电流实测。
