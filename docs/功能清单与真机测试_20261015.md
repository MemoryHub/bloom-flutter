# 本次功能与真机测试

## 本次功能

1. 相框在常驻蓝牙待机期间仍可被发现；设备打开 App、查看列表/详情/Wi-Fi 页面不主动扫描、连接或操作相框。
2. 已绑定设备的 Wi-Fi 管理使用独立页面。点击添加或确认删除后，依次显示连接相框、主人验证和执行进度，不经过取名、第一张照片或四步向导。
3. 主人管理凭证使用 P256。首次绑定/另一台手机首次管理需联网取得授权；已授权手机的日常 Wi-Fi 添加删除经本地加密蓝牙完成。账号切换、解绑与取消均有对应保护。
4. Wi-Fi 异步扫描、列表分页及长回复分片；目标 Wi-Fi 真正关联并取得 IP 后才保存。错密码或保存失败不会覆盖原网络；最多保存 6 个网络。
5. 删除备用网络保留当前连接；删除当前网络尝试其他已保存网络；删除最后一个后仍保留蓝牙供再次添加。
6. 已被另一台手机连接时继续广播占用状态，显示占用提示；退出/取消/后台释放，未验证连接和管理连接均有超时。
7. 待机复用原选图、缓存、轮播及 ULP 方向逻辑；绝对换图准备点优先，转向继续只读当前图片缓存。配网遇到换图或转向会中断候选操作，未成功候选不保存。
8. 原首次开箱、已有照片首播进度、正常解绑返回欢迎与 OTA 机制保留。解绑和 OTA 仍是原云任务流程，没有新增通用即时蓝牙唤醒入口。

## 优先级最高：轮播与横竖切换

| 用例 | 操作 | 预期结果 |
|---|---|---|
| 1 正常轮播 | 保持平常作息/间隔，连续观察至少 3 个正常换图点 | 每格按原计划换图；设备无循环重启、持续空转或停图 |
| 2 四姿态 | 同一照片分别摆为正竖、反竖、正横、反横，各稳定超过 8 秒；刷屏后等待保护时间再测 | 显示方向正确；沿用当前照片的另一方向缓存，不额外换照片 |
| 3 快速翻动 | 30 秒内连续翻动，然后保持一个姿态 | 防抖正常，没有连续刷新；最终稳定姿态得到正确画面 |
| 4 临近换图转向 | 在换图准备点/换图点附近切换方向 | 按原合并规则更新，没有双刷、错图或被配网推迟到下一格 |
| 5 管理冲突 | 点击添加 Wi-Fi，扫描/尝试连接期间恰逢换图或转向 | 相框优先完成轮播/转向；App 显示中断/忙碌或可重试，不假报配网成功 |
| 6 断网基础能力 | 暂时关闭路由器网络，观察有缓存的正常换图并转向，再恢复网络 | 缓存范围内仍轮播/转向；网络恢复后后续计划继续更新 |

## Wi-Fi 管理（先 iOS 单独测试，再 Android 重复）

| 用例 | 操作 | 预期结果 |
|---|---|---|
| 7 只浏览 | 打开 App → 设备 → 详情 → Wi-Fi，仅查看页面 | 页面展示摘要；没有“连接相框”进度、蓝牙配网或额外刷屏。若需确认内部状态，看脱敏日志 |
| 8 添加网络 | 点添加 Wi-Fi，手机靠近相框 | 显示连接/验证/获取列表，随后进入独立 Wi-Fi 列表；无取名/第一张照片四步骤 |
| 9 首次授权 | 新版第一次管理时保持手机联网 | 自动取得主人授权；以后该账号该手机使用缓存授权 |
| 10 错密码 | 选测试网络并输入错误密码 | 停在顶部“连接未完成”，显示失败原因、所选网络和重试/重新选择；原保存网络保留，列表不新增候选；无假成功 |
| 11 正确密码 | 重试输入正确密码 | 成功后完成按钮可用；返回 Wi-Fi 页面看到真实保存结果 |
| 12 取消/后台 | 扫描或连接中取消、返回，或将 App 切入后台 | 手机释放连接；候选未成功不保存；相框继续正常播放 |
| 13 删除备用网络 | 确认删除一个当前未连接的网络 | 先连接/验证，设备真删除后列表才移除；当前网络不被断开 |
| 14 删除当前网络 | 已保存另一个可用网络后，删除当前连接的网络 | 被删网络不反复重连；尝试其他保存网络；轮播正常 |
| 15 删除最后一个 | 确认可再次添加后，删除最后一个网络 | 网络列表为空，相框仍可蓝牙发现；手机靠近可重新添加网络，无需中键 |
| 16 手机无互联网 | 已在这台手机完成授权后关闭蜂窝数据；手机与相框近距离，进行本地网络管理 | 管理不因手机无法请求服务端而失败。手机不要关闭蓝牙；目标路由器本身应可关联取得 IP |
| 17 远离/关蓝牙 | 操作前远离相框或关闭手机蓝牙 | 明确找不到/蓝牙提示，可取消重试；列表不假变更、相框照片不被改动 |
| 18 换账号 | 切到另一账号，再尝试管理原主人相框 | 原账号私钥不会被新账号使用，非主人不能改 Wi-Fi |

| 20 闲置连接释放 | 添加页面停留超过管理超时，再操作 | 会话被释放或提示重新连接；没有永久占用，其他手机可管理 |

| 22 正常解绑 | 后续单独测试“解绑并重置”，保持云端照片 | App 依据真实设备执行回执完成，相框回欢迎页/专属二维码，私有缓存/网络/旧主人授权清理；云端照片保留。离线可能等原云任务机制，不能假报立即完成 |
| 23 首次开箱与首播 | 用例 22 真完成后扫码 → 取名 → Wi-Fi → 完成并开始播放 | 扫码先核验实物；Wi-Fi 列表正常，真实联网成功；已有照片显示首播按钮及真实进度，可后台运行，真实刷屏完成才出现完成按钮 |
| 24 无照片账号 | 仅用隔离的无照片测试账号/新设备走首次添加 | 维持原上传第一张照片引导；不删除当前主人图库来模拟 |

建议每次记录手机平台、步骤、提示原文、开始/结束时间及相框画面。轮播与转向有异常先停网络测试，保留日志。真实整板电流需要独立供电仪表测量；USB 串口状态和芯片资料不代替续航实测。OTA 真实失败回滚仍未验收，本次不自动发布 OTA。

## 独立供电补充测试

电脑 USB 连接时会关闭自动轻睡以保留维护通道。完成上述基础检查后，拔下电脑改用独立充电器或电池，重复蓝牙发现、添加网络、至少三个换图点及四姿态切换；这是自动轻睡环境的独立验收项。随后用仪表测整板平均待机电流和一次联网/刷屏能量。当前没有该环境的电流或续航实测结论。
